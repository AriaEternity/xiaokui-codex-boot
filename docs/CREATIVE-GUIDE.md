# 从自己的创意开始

小葵是本项目的演示主题。你可以做航天终端、海底实验室、复古游戏机、极简工作台或自己的角色；不必沿用粉色、樱花或这里的字幕。

## 准备一份小分镜

- 身份：角色或品牌是什么，给谁使用？
- 气氛：安静、清爽、复古、机械、神秘，选择一两个重点。
- 素材：透明 Logo、主色、字体选择、声音方向。
- 节奏：什么先出现，什么时候读字幕，怎样把注意力带到真实页面？
- 收尾：下方是什么应用，颜色和位置怎样衔接？动画不要在结束前承诺应用必定加载完成。

## 给绘图工具的示例描述

> 为我的原创【角色或品牌名称】设计一个启动画面使用的 Logo。主题为【主题】，主色为【颜色】，希望呈现【感觉】。输出透明背景 PNG，完整保留轮廓，构图清晰、适合在深色或浅色界面上展示。请先给出构图建议；不要沿用其他项目的角色，也不要使用无权使用的品牌标记。

这只是新创作的提示词模板，不是示例小葵 Logo 的原始生成提示词。AI 输出文字、透明边缘和小细节需要人工检查。

## 给 Codex 或其他编程助手的示例需求

> 我希望基于此项目，为自己的透明 PNG Logo 制作一段 Windows Codex 启动动画。主题是【主题】，主色是【颜色】，时长是【时长】，我希望传达【感觉】。请先讨论分镜，再修改代码。保留同步启动、窗口对齐和独立预览，字幕、进度和提示音共用一条时间轴。请根据主题重新设计运动与过渡，指出需要准备的素材和测试方法。避免修改官方安装包和账号，也不要把我的个人路径、凭据或聊天写进公开文件。

## 从小改动逐步做

先换 Logo 与字幕，确认构建可用；再改配色和粒子；最后重排运动与收尾。每一步都预览，比一次改完全部效果更容易判断哪里不合适。

你可以先描述效果，例如“像星图一样点亮，再聚成标志”，让编程助手把它拆成绘制步骤。图片生成工具负责静态素材，运动由动画代码实现；本项目没有让 AI 在运行时自动生成动画的接口。

欢迎提交自己的实现，但请使用有权使用的图片、声音和字体，并明确标注 AI 参与的部分。
