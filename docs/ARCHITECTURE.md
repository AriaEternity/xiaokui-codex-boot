# 实现方式

Logo 是静态 PNG，动画是程序逐帧绘制。AI 协助素材生成、代码编写和调试，运行过程不调用 AI。

1. build.py 用 Pillow 生成图标，用波形合成生成 WAV，调用系统 .NET Framework C# 编译器，将图片和声音嵌入 EXE。
2. Program 捕获鼠标所在屏幕的工作区，启动独立线程激活官方 Codex；主线程显示 WPF 动画窗口。
3. SakuraScene 用 DrawingContext 绘制图层。Logo 的有色非透明部分被采样为色块，按随机偏移与缓动曲线归位；扫描线、圆弧、粒子和文字由代码绘制。
4. BootWindow 用 Win32 探测官方客户端窗口并匹配边界。初次放置为共同居中矩形，之后跟随客户端；可见窗口始终保持覆盖层置顶。
5. Stopwatch 驱动全部视觉节点；截止定时器再次核对单调时钟。12.5 秒截止不依赖窗口就绪，减少探测影响时长的机会。
6. WPF 透明覆盖中，装饰、字幕、Logo、背景、进度分别控制透明度。真实客户端位于下方，在覆盖逐层退场时逐渐显露；不使用录制的真实聊天截图来伪装交接。

覆盖窗口保留角落一个物理像素的非矩形区域，沿用当前客户端遮挡绘制兼容策略；该策略仍需随未来 Windows/Codex 版本重新验证。它不是官方加载完成事件。

客户端标识和实际路径校验集中在 Native / Program。识别逻辑目前针对 Windows 商店版，不应未经验证扩展为任意同名进程。结束后释放渲染事件、探测挂钩、定时器与音频，不安装常驻监听。

进度条是动画时间进度；即使达到 100%，也不保证 Codex 首页全部加载完成。固定时长策略下，加载较慢时会自然显示官方加载页面。
